# Victoria Pirate Video Overlay

Grey transparent checkpoint cards for a 1280x720 gameplay video.

- Checkpoint 1: Pirate advancement, instructor training, and supplies
- Checkpoint 2: Nautilus Harbor quest pack and the level 15 goal
- `progress-frames/`: every ordered progress state in editable SVG and transparent PNG

Place gameplay on OpenShot Track 1 and a progress PNG on Track 4 or above. Start near `X = 800`, `Y = 18` in a 1280x720 project.
